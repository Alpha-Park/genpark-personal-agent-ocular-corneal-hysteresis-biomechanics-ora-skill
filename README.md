# GenPark Personal Agent: Ocular Corneal Hysteresis Biomechanics (ORA) Skill

A pure Python, zero-dependency FastMCP skill for non-contact dynamic corneal biomechanics and corneal-compensated intraocular pressure analysis.

## Features
- **Deterministic Biomechanical Equations**: Precise calculations for Corneal Hysteresis ($CH$), Corneal Resistance Factor ($CRF$), and Goldmann-correlated Intraocular Pressure ($IOP_g$).
- **Corneal-Compensated IOP ($IOP_{cc}$)**: Eliminates tonometric artifact caused by thin or floppy corneas, providing true intraocular pressure measurements.
- **Glaucoma & Ectasia Susceptibility Profiling**: Stratifies risk based on corneal damping capacity and resistance parameters.
- **Interocular Asymmetry Evaluation**: Identifies unilateral corneal ectasia or asymmetric glaucomatous damage between OD and OS.

## Installation & Usage
```bash
python example_usage.py
```
